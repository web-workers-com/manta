## Manta 0.4.10 – New tabs where you want them

- **New tabs open in:** Settings → General → Files lets you choose where ⌘T opens a new tab – the same folder as before, your home folder, Desktop, Documents, Downloads or a folder of your choice. Like Finder's "New Finder windows show"; a start without a saved session begins there too
- **New Tab in the Dock menu:** right-click Manta's icon in the Dock for **New Tab**, which also brings Manta to the front

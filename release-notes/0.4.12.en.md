## Manta 0.4.12 – ssh in the terminal opens the server in the pane

- **`ssh` in the terminal noticed:** type `ssh user@server` (or a host from your `~/.ssh/config`) in the local terminal and Manta offers **Open user@server in the pane** in the top-right corner. A click shows the server in the pane over SFTP – through an open connection, a matching favorite or the Connect dialog filled in. From then on pane and terminal follow each other as with Docker containers, and you can copy and move between the panes. Works in zsh, the macOS default shell

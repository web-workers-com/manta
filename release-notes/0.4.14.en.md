## Manta 0.4.14 – exit leaves the pane's server too

- **`exit` in a server's Terminal:** when the pane shows a server or share (SFTP, SMB, Docker, Kubernetes), `exit` in the Terminal now leaves it in the pane too: the pane goes back to the folder on your Mac it was in before, and the connection closes unless another tab still shows it. If the shell ends otherwise, say because the connection dropped, the pane stays where it is

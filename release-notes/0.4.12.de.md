## Manta 0.4.12 – ssh im Terminal öffnet den Server im Bereich

- **`ssh` im Terminal erkannt:** Tippst du im lokalen Terminal `ssh user@server` (oder einen Host aus deiner `~/.ssh/config`), bietet Manta oben rechts **„user@server im Bereich öffnen“** an. Ein Klick zeigt den Server per SFTP im Bereich – über eine offene Verbindung, einen passenden Favoriten oder den fertig ausgefüllten Verbindungsdialog. Danach folgen Bereich und Terminal einander wie bei Docker-Containern, und du kannst zwischen den Bereichen kopieren und bewegen. Funktioniert in der zsh, der Standard-Shell von macOS
